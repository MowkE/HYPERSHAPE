How do I make a shape? (20 seconds)

A shape is just a list of points. Every point is 4 numbers: [x, y, z, w]. The 4th number is the one your eyes can't see — so it becomes color. Connect points with edges and return { verts, edges }. That's the whole secret.

Cheat codes: minDistEdges(verts) connects every closest pair of points for you · gridSurface((u,v) => [x,y,z,w], {nu, nv}) weaves a whole sheet · paramCurve(t => [x,y,z,w], {n}) draws a glowing thread · merge(a, b) glues shapes together · triCliques(n, edges) adds faces so the CT-scanner can slice it.

Pick an example below, press ▶ Run, then change one number and run it again. That's how everyone learns.
